# College Athlete Planner

## Project Description
College Athlete Planner is an application designed to help college student-athletes manage their academic and athletic responsibilities in one place.

The application helps athletes organize classes, assignments, practices, workouts, and personal responsibilities.

## Main Features
1. **Calendar:** Organize classes and football practices.
2. **Task Manager:** Track assignments and deadlines.
3. **Workout Tracker:** Record training activities.
4. **Dashboard:** Display upcoming responsibilities.

## Technology Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js and Express
- **Database:** SQLite
- **Containerization:** Docker
- **CI/CD:** GitHub Actions
- **Deployment:** Google Cloud

## AI Integration
GitHub Copilot and ChatGPT will assist with development, debugging, and improving code. AI may also help users organize schedules and prioritize upcoming responsibilities.

## Project Goal
The goal of College Athlete Planner is to make it easier for college student-athletes to balance academics, athletics, and personal responsibilities.
